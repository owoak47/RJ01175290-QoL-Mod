# RJ01175290 QoL Mod 1.0.9（朋友分享版）

支援：Windows、遊戲 **1.4.4＋rev.3／rev.4**，與本套件核對過的原版腳本。不是完整遊戲，朋友需自行備有一般版遊戲。

## 包含功能

- 武器、裝備背包容量各9999；一般道具每種上限250。
- 武器、裝備同款堆疊，右下角顯示數量；點擊展開獨立物品，武器可按各自耐久選擇。
- 五頁套裝：一把武器、五件裝備、七格道具快捷欄。從三種背包介面皆可切換，離開背包後套用。Shift＋點分頁可用目前配置覆寫該頁；配置隨正常存檔保存。
- 稻草人最近一秒DPS與最高單次傷害。
- 目前七處Boss營火配置，以及傳往八腕營火時的黑畫面處理。沿用既有地圖、事件與部分擊殺條件；不含薩卡班甲魚王、ASABA、劍聖、淫奔惡魔營火。
- 減少高更新率螢幕上同一邏輯幀的重複繪圖，不改遊戲速度或螢幕更新率。不是所有卡頓的通用修復。
- 道具原有數量超出250時，取得不會刪除超額物品，使用仍正常扣除。

**不包含固定數量效果**：茶點心券、節制、ASABA草莓都正常取得與消耗。不包含作者存檔、角色資料、遊戲本體或美術素材。

## 安裝

1. 正常關閉遊戲，另留一份原版與存檔備份。
2. 解壓縮本ZIP，執行 `Install.cmd`。
3. 貼上朋友自己的遊戲資料夾路徑，即 `Game.exe` 所在資料夾；也支援指定 `bin\www`。
4. 出現「安裝完成」後，正常啟動原本的 `Game.exe`。

不需要Node.js、Python或Anaconda，安裝器使用Windows內建Windows PowerShell。此套件不是放進mods資料夾就自動啟用的格式。若遊戲資料夾沒有寫入權限，請改放到可寫入的資料夾，或以管理員執行安裝器。

安裝前會檢查版本、必要插件與七個修補檔的完整內容雜湊。全部通過才差異修補；不整份覆蓋未知版本。原有插件設定會保留。首次安裝會在遊戲 `bin\www\.rj-qol-backups` 建立備份，並記錄 `.rj-qol-mod.json`；請保留兩者。

偵測到固定物品數量的自用版本時會拒絕安裝，保留原設定。若顯示「不支援的檔案版本或其他Mod修改」，代表與已驗證的一般版不同，請勿強行覆蓋。

## rev.3 相容性

rev.3的玩家腳本新增「事件執行中暫不強制回家」修正，本包已保留。本包使用rev.3的完整內容雜湊及差異修補資料，沒有用舊版整檔蓋回新版。舊修訂請用先前1.0.2包；新增熔岩Boss火點僅在rev.3驗證。

## 移除與更新

執行 `Uninstall.cmd`，指定同一份遊戲即可還原安裝前程式與插件清單。還原前也會校驗檔案；遊戲更新或其他Mod改動同一檔案時會停止，避免用舊備份覆蓋新檔。

舊版Mod仍完整時，先使用本包的Uninstall.cmd還原，再安裝新版。若已被遊戲更新完整恢復七個原版腳本，新安裝器可檢查後重新安裝，並以更新後程式建立新備份；半套更新或未知修改會拒絕覆蓋。

**遊戲更新前先移除本Mod**。更新後需重新檢查相容性；目前不承諾支援1.4.3、rev.1／rev.2／rev.3以外的修訂或未來版本。

安裝及移除都不改寫存檔。移除不回退遊戲進度：已寫入存檔的營火、配置頁等資料可能仍保留。要完整回到使用Mod以前的狀態，請還原自己安裝前的存檔。還原程式後容量回到原版規則，超額背包建議先整理。

## 1.0.4戰後營火修正

原版冰／水彈會把營火切到無互動指令的熄滅頁。熔岩場新火點可能在戰鬥中被波及，因此戰後靠近沒有反應。本版只讓地圖72、座標(22,15)的新增營火，在龍娘戰鬥／倒地結算完成後自動重燃；戰鬥中仍維持原生互動限制。其他地圖、其他營火的冰水反應不變。已熄滅存檔讀取後也會恢復。

已以原生冰彈碰撞重現修正前不能互動，修正後同一流程可開選單；另測試完整倒地事件、熄滅存檔重載及普通營火仍可熄滅。

## 1.0.6：Aki 尋人面板

地圖右上角點「尋找 Aki」或按 F6 展開。Aki 在同圖出攤時，面板顯示方向、直線距離和座標，店員頭上標記「▼ Aki」。未找到時，列出原生出攤區域，以及下雨或本輪出攤機會已用過的提示。方向是直線方位，仍需繞過地形。

不改出攤機率、不生成商店、不傳送玩家。介面每半秒更新一次，對話與事件期間隱藏。

從 1.0.5 升級：請先使用舊套件的 Uninstall.cmd 移除，再執行本套件 Install.cmd；存檔不受影響。

## 1.0.7：數字鍵快速換裝

鍵盤上排 1～5，或 Num Lock 開啟時的小鍵盤 1～5，對應五頁套裝。地圖上立即套用整套武器、裝備、七格道具快捷欄與已選道具；背包內則切換預覽頁，離開背包後結算。

請先在背包中配置套裝。地圖快捷鍵不會建立或覆寫空頁；缺件、獨立物品不符或欄位鎖定時拒絕整套切換。對話、事件、傳送、死亡與背包拖曳／選擇視窗期間停用；按住數字不會重複切換，Ctrl／Alt／Shift 組合鍵保留。

沿用原生完整換裝結算，正確移出／放回裝備並更新裝備效果；不複製物品，不重置耐久。頁面隨正常存檔保存。

升級舊套件請先以舊版 Uninstall.cmd 移除，再執行本版 Install.cmd。

## 一鍵更新（1.0.9）

第一次請保留本資料夾並執行 Update.cmd，輸入 Game.exe 所在的路徑。更新器會從 https://github.com/owoak47/RJ01175290-QoL-Mod/releases/latest 下載已發布的朋友版、檢查 SHA256、建立備份後安裝。完成後桌面會新增「更新朋友版 Mod」，之後直接執行即可，不用再請朋友傳檔。

更新前請儲存並正常關閉遊戲。舊版完整安裝會自動還原後升級；遊戲更新覆寫 Mod 時會重新比對支援版本與原始檔。未知版本或其他修改會停止，不會硬套。更新失敗會還原更新前的 Mod 檔案，不更動存檔。現有五套換裝設定仍保留在原存檔。

更新器儲存在使用者 LocalAppData\RJ01175290-QoL-Updater，只記住遊戲路徑，不上傳任何遊戲或存檔。預設不需 Python、Node 或 Anaconda。
