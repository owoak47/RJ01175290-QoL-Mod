# RJ01175290 QoL Mod 1.0.11

支援 Windows 上的遊戲 1.4.4 rev.3、rev.4、rev.5、rev.6 與 1.4.5 rev.1。請使用自己持有的遊戲；安裝器會進一步核對遊戲檔案是否相容。

## 包含功能

- 武器和裝備背包容量各提升至 9999；一般道具每種上限為 250。已有超過上限的道具可繼續正常使用。
- 相同武器與裝備堆疊並顯示數量；可展開並選擇個別物品，武器保留各自耐久。
- 五頁套裝，包含武器、裝備與道具快捷欄。背包中 Shift＋點擊分頁可覆寫配置；上排數字鍵 1～5 或開啟 Num Lock 後的小鍵盤 1～5 可切換套裝。套裝隨存檔保存。
- 稻草人顯示最近一秒 DPS 與最高單次傷害。
- Boss 附近營火傳送點，包含熔岩決戰場；改善八腕營火傳送黑畫面與熔岩營火戰後互動。
- 尋找 Aki：按 F6 或點擊畫面右上角展開提示；同地圖出攤時顯示方向、直線距離和座標。
- 調整重複繪圖，改善部分高更新率螢幕的負載。

## 安裝

1. 儲存進度並正常關閉遊戲，備份遊戲和存檔。
2. 解壓縮後執行 `Install.cmd`，輸入 `Game.exe` 所在資料夾；也可以指定 `bin\www`。
3. 安裝完成後正常啟動遊戲。

安裝器會檢查遊戲版本、插件和待修補檔案，並建立備份。若檔案與支援版本不同，安裝器會停止並顯示原因。遊戲資料夾需要寫入權限。

## 更新

首次執行 `Update.cmd` 並輸入遊戲資料夾後，更新器會下載 GitHub 上已發布的最新版，並建立桌面更新捷徑。每次更新前請儲存並關閉遊戲。新遊戲版本需經相容性檢查後才能安裝。

更新來源：[GitHub Releases](https://github.com/owoak47/RJ01175290-QoL-Mod/releases/latest)。

## 移除

儲存進度、關閉遊戲後執行 `Uninstall.cmd`，指定同一份遊戲資料夾。安裝器會檢查並還原備份；若遊戲更新或其他修改影響還原檔案，會停止並顯示原因。移除程式不會回退遊戲進度，存檔中的套裝與營火紀錄可能仍保留。

## 1.0.11 相容性

此版新增 1.4.5 rev.1 的差異修補資料，並保留 1.4.4 rev.3～6 的對應資料。1.4.5 rev.1 的封裝與原始檔差異已核對；實際遊戲內操作仍需驗證。`SHA256SUMS.txt` 可用來核對套件檔案完整性。
