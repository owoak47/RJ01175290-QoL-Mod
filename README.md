# RJ01175290 QoL Mod（朋友版）

支援遊戲 **1.4.4 rev.3／rev.4／rev.5**。本儲存庫只包含 Mod、差異修補與更新工具，沒有完整遊戲或存檔，也不包含固定物品數量功能。

## 第一次使用

1. 從 [最新版下載](https://github.com/owoak47/RJ01175290-QoL-Mod/releases/latest/download/RJ01175290-QoL-Mod.zip) 下載 ZIP 並解壓縮。
2. 儲存並正常關閉遊戲。
3. 執行 `Update.cmd`，輸入 `Game.exe` 所在資料夾。
4. 完成後，桌面會出現「更新朋友版 Mod」。以後按它即可檢查並安裝更新，不需要朋友重新傳檔。

更新器會記住遊戲路徑，下載後校驗 SHA256。舊版完整安裝會自動還原並升級；遊戲更新後會檢查相容性，遇到未知版本或其他修改就停止。更新失敗會還原更新前檔案，不上傳或修改存檔。遊戲未來改版仍需發布相容的 Mod，更新器不會強套未知版本。

## 功能

- 武器與裝備持有上限 9999、一般道具上限 250。
- 相同武器、裝備與道具堆疊顯示；獨立耐久與個別選擇保留。
- 五套換裝頁面，數字鍵 1–5 快速切換。
- 稻草人最近一秒 DPS、最高單次傷害。
- Boss 營火與傳送修正。
- F6 尋找 Aki，同地圖顯示方向、距離與標記。
- 畫面更新節奏調整。

原始遊戲的內容與權利屬於原作者。此為非官方便利功能 Mod。

## 維護與發布

`bundle/` 是朋友版發行來源。確認新遊戲版本及修補結果後，更新 `bundle/manifest.json` 的版本與相容資料、SHA256SUMS.txt，再提交 main。GitHub Actions 會打包並發布同名的最新版資產；已發布版本不覆寫。不要提交遊戲原始檔、存檔、備份或登入憑證。
